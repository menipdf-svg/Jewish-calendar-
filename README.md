# יומן עברי 🕯️

לוח שנה עברי בעיצוב של יומן גוגל – עם כל זמני ההלכה במקום אחד.

## מה יש בפנים

- **תצוגות**: חודש, שבוע, יום ולוח זמנים (כמו ביומן גוגל), מסך קטן וגדול, מצב כהה.
- **תאריך עברי ולועזי** בכל יום, כולל שמות חודשים ושנה בגימטריה.
- **כניסת שבת, הדלקת נרות וצאת שבת/חג** לפי המיקום שנבחר.
- **זמני היום**: עלות השחר, משיכיר, הנץ, סוף זמן ק״ש ותפילה (גר״א ומג״א), חצות, מנחה גדולה וקטנה, פלג המנחה, שקיעה, צאת הכוכבים, חצות הלילה.
- **פרשת השבוע**, שבתות מיוחדות ושבת מברכים, חגים ומועדים (ארץ ישראל / חו״ל), ראש חודש, צומות, ימים מיוחדים, ספירת העומר, מולד הלבנה ודף יומי.
- **מיקום**: ערים בישראל ובחו״ל, או "המיקום שלי". אפשר לשנות דקות הדלקת נרות ושיטת צאת הכוכבים (8.5°, 42, 50, 72 דקות).
- **ייצוא ל-ICS** לייבוא ליומן גוגל / אפל / אאוטלוק.
- קיצורי מקלדת: `T` היום · `J`/`K` הקודם/הבא · `M` חודש · `W` שבוע · `D` יום · `A` לוח זמנים.

## הרצה

פשוט לפתוח את `index.html` (או להעלות ל-GitHub Pages: Settings ← Pages ← Branch `main` / root).
קובץ ה-JavaScript המהודר נמצא ב-`dist/app.js`, כך שלא נדרש build כדי להפעיל.

## פיתוח

```bash
npm install
npm run build   # בונה את dist/app.js מתוך src/app.js
npm run dev     # בנייה אוטומטית בזמן עריכה
```

החישובים מבוססים על [@hebcal/core](https://github.com/hebcal/hebcal-es6) ו-[@hebcal/learning](https://github.com/hebcal/hebcal-learning).

> הזמנים מחושבים לפי קואורדינטות המיקום. לפסיקה הלכתית יש להיוועץ ברב.
