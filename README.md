# יומן עברי – אפליקציית אנדרואיד

לוח שנה עברי בעיצוב של יומן גוגל, כתוב כולו ב-**Kotlin + Jetpack Compose**.

## מה יש בפנים

- תצוגות חודש, שבוע, יום ולוח זמנים; מצב כהה; החלקה בין חודשים וימים.
- תאריך עברי ולועזי בכל יום.
- כניסת שבת, הדלקת נרות וצאת שבת/חג לפי המיקום.
- זמני היום: עלות השחר, משיכיר, הנץ, סוף זמן ק״ש ותפילה (גר״א ומג״א), חצות, מנחה גדולה וקטנה, פלג, שקיעה, צאת הכוכבים.
- פרשת השבוע, שבתות מיוחדות, חגים (ארץ ישראל / חו״ל), ראש חודש, צומות, ספירת העומר ודף יומי.
- ערים בישראל ובחו״ל או "המיקום שלי"; דקות הדלקת נרות ושיטת צאת הכוכבים ניתנות לשינוי.

## התקנה

כל push ל-`main` בונה APK ב-GitHub Actions ומפרסם אותו ב-Releases:
https://github.com/menipdf-svg/Jewish-calendar-/releases/latest

## בנייה מקומית

פותחים את התיקייה ב-Android Studio, או:

```bash
./gradlew assembleDebug
```

החישובים מבוססים על [KosherJava Zmanim](https://github.com/KosherJava/zmanim). לפסיקה הלכתית יש להיוועץ ברב.
